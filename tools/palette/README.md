# Block category pipeline

The color palette and the block-category map are deliberately separate. The
palette is generated from a particular Minecraft client JAR, while
`block-categories.json` maps stable namespaced block IDs to reusable English
category IDs and does not contain a Minecraft version.

## Files

- `input/block-names-1.21.1.txt` is generated by
  `tools/VanillaPaletteGenerator.java` after full-cube, opacity, and falling
  block filtering.
- `classification/block-categories.txt` is the reviewed, tab-separated source
  mapping. Its format is `block_id<TAB>category,category`.
- `BuildBlockCategories.java` strictly validates exact input coverage, IDs,
  category names, duplicates, and ordering before writing JSON.
- `ApplyBlockCategories.java` applies that reusable map to a generated
  version-specific color palette and requires exact block coverage.
- `src/main/resources/assets/minesplat/palette/block-categories.json` is the
  version-independent generated mapping that can be intersected with a color
  palette from any Minecraft version after that palette is generated.

## Categories

- `all` — every eligible opaque, non-falling full-cube block.
- `survival` — blocks obtainable as placeable items in ordinary vanilla
  Survival.
- `solid_colors` — plain, color-oriented building blocks such as wool,
  concrete, and terracotta. Strongly patterned variants are excluded.

## Build the JSON

```sh
java tools/palette/BuildBlockCategories.java \
  tools/palette/input/block-names-1.21.1.txt \
  tools/palette/classification/block-categories.txt \
  src/main/resources/assets/minesplat/palette/block-categories.json
```

For a later Minecraft version, generate a new block-name input and reuse the
existing mapping for matching IDs. New IDs must be explicitly classified
before rebuilding, so silent category omissions cannot enter a release.

## Apply categories to generated colors

The palette generator writes colors and block states without embedding category
policy. Apply the separately maintained mapping afterwards:

```sh
java -cp "path/to/gson.jar" tools/palette/ApplyBlockCategories.java \
  generated-palette.json \
  src/main/resources/assets/minesplat/palette/block-categories.json \
  src/main/resources/assets/minesplat/palette/palette-1.21.1.json
```
